# Fotos dos produtos

As fotos reais entram aqui (ex.: `matcha.jpg`, `capuccino.jpg`).

Para exibir uma foto, preencha o campo `image` do produto em `src/data/products.ts`
com o **nome do arquivo** — o card troca do placeholder para a foto sozinho, sem
mexer em nenhum componente. Formatos aceitos: jpg, jpeg, png, webp, avif.

Enquanto o campo `image` estiver ausente, o card usa o `ImagePlaceholder`
(emoji + gradiente creme).
